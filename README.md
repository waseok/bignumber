# 큰 수 챔피언

4학년 학생이 큰 수를 읽고 비교하는 활동을 전자칠판이나 태블릿에서 동시에 진행할 수 있는 웹게임입니다.

## 기능
- 최대 6인 동시 참여
- 난이도 하, 중, 상 선택
- 읽기, 비교, 혼합 문제 모드
- 조 단위까지 문제 출제
- 효과음 토글과 라운드 애니메이션
- 교사용 설명 패널 제공

## 실행 방법
1. `C:\codex\bignumber\index.html`을 브라우저에서 엽니다.
2. 참가 인원, 난이도, 문제 유형, 라운드 수를 고릅니다.
3. `게임 시작`을 눌러 수업을 진행합니다.

## 배포
이 저장소에는 GitHub Pages용 워크플로가 포함되어 있습니다.
원격 저장소를 GitHub에 연결하고 기본 브랜치로 푸시한 뒤, 저장소의 Pages 설정에서 GitHub Actions를 사용하도록 두면 자동 배포됩니다.
